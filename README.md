# Yara Glow — موقع حجز مركز تجميل

موقع ويب لصفحة حجز مركز تجميل **Yara Glow**، مكتوب بالعربية مع دعم RTL كامل، ومتجاوب على جميع الأجهزة (هاتف / تابلت / كمبيوتر).

## المميزات
- تصميم أنيق بألوان دافئة (بيج، ذهبي، وردي فاتح).
- قسم خدمات بأربع بطاقات (الخدمة، المدة، السعر، المزوّدة).
- مسار حجز متعدد الخطوات (5 خطوات): الخدمة ← المزوّدة ← التاريخ ← الوقت ← بيانات العميلة.
- خطوة أخيرة تعرض ملخّص الحجز (الخدمة، المزوّدة، الموعد، السعر) مع نموذج (الاسم، الهاتف، ملاحظات).
- منع حجز نفس الوقت لنفس المزوّدة مرتين (تحقّق عند اختيار الوقت وعند التأكيد)، ورسالة نجاح للعميلة.
- تقويم تفاعلي يمنع اختيار تواريخ الماضي.
- عرض الأوقات المتاحة حسب مدة الخدمة، مع إخفاء الأوقات المحجوزة والماضية.
- حفظ الحجوزات في `LocalStorage`.

## البنية
```
index.html        الصفحة الرئيسية
admin.html         لوحة التحكم المحمية
css/styles.css     التنسيقات (RTL)
css/admin.css      تنسيقات لوحة التحكم
js/app.js          منطق الحجز
js/admin.js        منطق لوحة التحكم
assets/            الصور (SVG)
```

## لوحة التحكم (admin.html)
- **محمية بكلمة مرور** (افتراضياً `yara2026` — غيّريها من أعلى ملف `js/admin.js`).
- تعرض الحجوزات **مرتّبة حسب أقرب موعد** (القادمة أولاً).
- **فلترة** حسب اليوم، المزوّدة، والحالة.
- أزرار لتغيير حالة كل حجز: **جديد / مؤكد / مكتمل / ملغى**، وتُحفظ الحالة فوراً وتُلوَّن البطاقة حسبها.
- **عدّاد لمواعيد اليوم** إضافة إلى بطاقات إحصائية (قادمة، مؤكدة، مكتملة، ملغاة).

### إدارة الخدمات (تبويب «الخدمات» في اللوحة)
- **إضافة / تعديل / حذف** الخدمات.
- تحديد **أيام العمل** لكل خدمة و**ساعات الدوام** (بداية ونهاية).
- **أكثر من مقدّمة خدمة** لكل خدمة (تُدخل مفصولة بفواصل).
- التعديلات تنعكس فوراً على صفحة الحجز: خطوة اختيار المزوّدة تعرض جميع المقدّمات،
  والتقويم يعطّل أيام الإجازة، والأوقات تُحسب ضمن ساعات دوام كل خدمة.
- الخدمات تُخزَّن في `LocalStorage` (المفتاح `yaraGlowServices`) كمصدر مشترك بين الموقع واللوحة.

> البيانات تُخزَّن في `LocalStorage` بالمتصفّح كقاعدة بيانات مبسّطة. الحماية من طرف
> العميل مناسبة للاستخدام الداخلي؛ لحماية أقوى استخدمي `.htpasswd` في Hostinger.

## الرفع على Hostinger
1. فُكّ ضغط ملف `yara-glow.zip`.
2. ارفع محتويات المجلد (index.html والمجلدات css / js / assets) إلى `public_html` عبر مدير الملفات أو FTP.
3. افتح نطاقك — الموقع جاهز للعمل مباشرةً دون أي إعدادات إضافية.

> ملاحظة: الصور الحالية عبارة عن صور SVG راقية كعيّنات، ويمكن استبدالها بصور حقيقية للخدمات بنفس أسماء الملفات في مجلد `assets`.
